# DOM and Event Handling

This project demonstrates basic DOM manipulation and event handling in JavaScript.

## Features
- Displays a greeting message on the page
- Uses a button click event to greet the user by name
- Includes color boxes that change background color when clicked
- Uses JavaScript event listeners instead of inline JavaScript

## Files
- `index.html` - Page structure
- `style.css` - Styling for the layout and boxes
- `script.js` - Event handling and DOM updates

## How to Use
1. Open `index.html` in a browser.
2. Type a name in the input field and click the button.
3. Click any color box to change its background color.

## Notes
This project is a beginner-friendly example of interacting with DOM elements using JavaScript events.
